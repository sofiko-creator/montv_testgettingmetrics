# montv_testgettingmetrics
Описание: Данный проект был реализован с целью протестировать поступление метрик в топики Kafka. Выполняется проверка структуры метрик на нужный состав полей, на лишние, недостающие поля и поля со значениями null. Проверяется, что метрики приходят примерно раз в 10 секунд, если нет, то записываются ошибки.

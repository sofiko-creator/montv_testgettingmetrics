# MonTV_Test_Getting_metrics
Описание: Данный проект был реализован с целью протестировать поступление метрик в топики Kafka iq_flow, iq_pid, iq_flow_etr, iq_program, iq_flow_structure.
Выполняется проверка структуры метрик на нужный состав полей, на лишние, недостающие поля и поля со значениями null. Файл: test_structure_server.py. 
Проверяется, что метрики приходят примерно раз в 10 секунд, если нет, то записываются ошибки. Файл: test_timing_server.py.

## Запуск тестов
1) Сначала нужно установить зависимости проекта командой "poetry install".
2) Создать .env файл, не отслеживаемый гитом. Он должен содержать значения для следующих переменных:
 * SERVER_ADDRESS - адрес сервера, на котором запущен брокер Kafka
 * PORT_NUMBER - переменная содержит номер порта, на котором брокер Kafka слушает входящие соединения
 * ID_DVB_C_ANALYZER_CRICKET - идентификатор анализатора, можно найти во вкладке Refbook "Анализаторы"
 * ID_IPTV_ANALYZER_G2X - идентификатор анализатора, можно найти во вкладке Refbook "Анализаторы"
 * ID_IPTV_ANALYZER_SURVEYOR - идентификатор анализатора, можно найти во вкладке Refbook "Анализаторы"
3) Для запуска тестов и формирования отчёта используется команда "pytest --alluredir allure-results"

## Текущее состояние тестов
На данный момент запускаются тесты для топиков Kafka (файлы test_structure_server.py и test_timing_server.py).
В test_timing_server.py и test_structure_server.py можно регулировать промежуток времени за который будут проверяться метрики. Для этого нужно изменять параметр duration_seconds в методе get_values_from_kafka_topic.
К примеру, все тесты для проверки таймингов при duration_seconds = 5000 (секунд) прошли примерно за 11 минут.
